## 📌 About the Project

This project is a basic university website designed to present information about NIST University in a simple and user-friendly layout.

## ✨ Features

- 🏠 Home section
- ℹ️ About section
- 🎓 Courses section
- 👨‍🏫 Faculty information
- 🏢 Facilities section
- 📝 Admission form
- 📍 Contact information
- 🗺️ Google Maps location
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
